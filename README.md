# Anushka Sangal — Portfolio

A recruiter-focused responsive portfolio website.

## Included
- Dark/light modern developer design
- Profile photo
- About, experience, projects, skills and education
- GitHub + LinkedIn links
- Smart Campus and Wanderlust live links
- Recruiter contact form using `mailto:`
- Responsive mobile layout

## Before publishing
1. Add your final resume as `resume.pdf` in the project root.
2. If you want direct project GitHub buttons, replace the current GitHub-profile links with the exact repository URLs.
3. For a true server-side contact form (without opening the recruiter's email app), connect Formspree, Web3Forms, or another form backend.

## Publish
This is a static site and can be deployed directly to Vercel, Netlify, or GitHub Pages.
